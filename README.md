    <p><strong>Last Updated: November 2026</strong></p>

    <p>This privacy policy governs your use of the software application <strong>TorqueMedic</strong> for mobile devices. TorqueMedic operates as an OBD2 telemetry interface scanner.</p>

    <h2>1. Real-Time Data Processing (OBD2)</h2>
    <p>TorqueMedic requests, reads, and parses real-time vehicle diagnostic data (including but not limited to Engine RPM, Vehicle Speed, and Diagnostic Trouble Codes) from your vehicle via a connected ELM327 Bluetooth hardware adapter. <strong>This data is strictly processed locally on your mobile device in real-time. It is never uploaded to external servers, stored permanently, or shared with third parties.</strong></p>

    <h2>2. Bluetooth Permissions Usage</h2>
    <p>Our application requires explicit Bluetooth hardware permissions to scan for, pair with, and establish a serial data link connection to your physical OBD2 adapter. Disabling Bluetooth permissions will prevent the application from communicating with the vehicle hardware.</p>
